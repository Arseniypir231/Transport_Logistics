# Аналитика и drag-and-drop

В проект добавлена страница `/analytics`.

Данные берутся из реального состояния приложения через REST API:

- `GET /api/analytics?period=6m`
- `GET /api/analytics?period=12m`

На странице реализованы графики через `Chart.js` и `react-chartjs-2`:

- линейный график динамики суммы заявок и количества рейсов по месяцам;
- круговая диаграмма распределения рейсов по статусам;
- столбчатая диаграмма топ маршрутов по количеству рейсов и сумме заявок.

В графиках есть русские заголовки, легенды, подписи осей и tooltip. Для аналитики доступен фильтр периода: 6 или 12 месяцев.

Drag-and-drop реализован через `@dnd-kit/core` и `@dnd-kit/sortable`: карточки графиков можно перетаскивать и менять местами. Порядок карточек сохраняется в `localStorage` по ключу `tl_analytics_cards`.
